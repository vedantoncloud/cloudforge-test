# CloudForge 🚀

![CloudForge Architecture](images/cloudforge-flow.png)

## Overview

CloudForge is a Mini Platform as a Service (PaaS) built using FastAPI, Docker, and MySQL.

The platform automates the workflow of taking a GitHub repository, cloning it, building a Docker image, deploying a container, and tracking deployments.

## Features

* JWT Authentication
* User Registration & Login
* Multi-user Authorization
* GitHub Repository Integration
* Automatic Repository Cloning
* Docker Image Building
* Container Deployment
* Deployment Tracking
* Build Logs
* Container Management
* MySQL Database Integration

## Tech Stack

* Python
* FastAPI
* Docker
* MySQL
* SQLAlchemy
* Git & GitHub
* JWT Authentication

## Workflow

User → Login → Create Project → Clone Repository → Build Docker Image → Deploy Container → Running Application
